快速起步與系統常駐

KyteShelf 採用極致輕量原生架構設計，安裝過程僅需數秒，且運行時記憶體佔用極低（約 30~50MB），全天候在後台為您待命。

安裝與啟動

執行下載的 KyteShelf_Setup_v1.3.0.exe，按照引導完成安裝。安裝完成後勾選「啟動 KyteShelf」即可立即開始使用。

系統匣 (工作列右下角托盤)

啟動後軟體會常駐於 Windows 工作列右下角托盤。在 KyteShelf 圖示上點擊滑鼠右鍵，即可呼叫主選單：

  • 顯示所有置物架：瞬間喚醒所有已存在的置物架視窗。
  • 📋 剪貼簿快速入架：自動提取剪貼簿內容並存入置物架。
  • 📑 置物架清單：依名稱切換、快速定位或重新命名置物架。
  • ⚙️ 偏好設定：自訂滑鼠晃動靈敏度、全域召喚快捷鍵與主題色彩。
  • 🔑 軟體授權 / 開通專業版：檢視目前授權狀態（試用期剩餘天數 / 永久專業版）或輸入序號。
  • 👀 設定監控資料夾：開啟自動偵測入架功能。

置物架召喚與隱藏機制

KyteShelf 提供了多種直覺召喚方式，無需中斷手頭工作即可在游標旁隨時調用。

方式一：滑鼠晃動召喚 (Shake to Summon)

在桌面或檔案總管中，按住滑鼠左鍵抓住檔案，輕微往左右快速搖晃 1~2 下，置物架便會瞬間彈出在游標身旁。放開滑鼠即可將檔案存入。

方式二：全域快捷鍵召喚

無論當前處於什麼全螢幕遊戲、瀏覽器或編輯器中，按下預設快捷鍵 Ctrl + `（Tab 上方的波浪鍵），置物架立即在滑鼠當前位置現身！

智慧釘選（Pin）與防手滑防吞噬保護： 點擊置物架右上角的「圖釘 📌」圖示即可將置物架固定於桌面最上層，不會隨視窗切換而隱藏。
若未釘選，當您點擊其他視窗時，置物架會自動優雅隱藏，但裡面的所有檔案依然安全儲存，下次召喚隨時原貌呈現！

多元入架模式 (萬物皆可收納)

KyteShelf 不僅僅支援一般電腦檔案，更打通了剪貼簿、截圖影像、純文字自黏便箋與網頁資源。

1. 滑鼠直接拖曳（支援批次）

框選 1 個或多達數十個檔案、資料夾，直接拖曳到置物架視窗內部放開即可。置物架會自動讀取檔案圖示、名稱與檔案大小。

2. 剪貼簿貼上 (Ctrl + V)

置物架現身後，直接按下鍵盤 Ctrl + V 或點擊底部「貼上」按鈕，KyteShelf 會智慧識別剪貼簿型態：

  • 檔案總管複製的檔案 ➔ 直接收納入架。
  • 螢幕截圖（如 Win + Shift + S 截圖或瀏覽器複製影像） ➔ 自動轉換為 PNG 實體檔案並建立縮圖！
  • 純文字筆記 ➔ 自動轉換為高質感黃色「自黏便箋（Sticky Note）」，可雙擊放大編輯！
  • 網址 URL ➔ 若為圖片網址會自動抓取存檔，一般網址則轉換為連結便利貼。

3. 資料夾即時監控自動入架 (Watch Folder)

在托盤選單點擊「👀 設定監控資料夾...」，選擇您的「下載（Downloads）」或「桌面」。往後只要瀏覽器下載完成任何新檔案，KyteShelf 就會在後台自動為您接進置物架，完全不需手動尋找！

04

出架傳輸、清架與 ZIP 壓縮打包

收集完畢後，如何高效將暫存檔案轉移至目標軟體或壓縮發送？

📋 複製模式 vs 🚚 搬移模式（拖出自動清架） 點擊底部標籤切換

在置物架左下角有一個操作模式按鈕，點擊可切換：

  • 📋 複製模式（預設）：將架內項目拖曳至桌面或通訊軟體後，置物架內的清單依然保留，適合重複引用同一批素材。
  • 🚚 搬移模式：拖出檔案成功轉移至目標視窗後，置物架自動清除該項目並清空，乾淨俐落無負擔！

📦 一鍵打包壓縮成 ZIP

當您從各處收集好 10 份合約或照片時，不必再開啟 WinRAR 或 7-Zip。直接點擊置物架底部的 「ZIP」 按鈕，系統會原地建立一個標準無失真的 ZIP 壓縮檔並自動儲存至桌面！

✉️ Outlook 郵件附件一鍵掛載

選取置物架內的一件或多件檔案，按滑鼠右鍵 ➔ 點選「寄送至 Outlook 郵件...」，KyteShelf 會透過 Windows 原生 COM 介面自動將檔案附加到您正在撰寫的 Outlook 郵件草稿中。

05

多置物架多工管理

面對大型專案時，您可以同時建立多個獨立置物架，將「待處理發票」、「設計素材」與「會議便箋」分別歸納。

＋

新增獨立置物架

點擊置物架標題列右上角的「＋」號，或托盤選單的「新增置物架」，即可開出新架。

重新命名置物架

雙擊頂部標題（如「置物架 #1」），即可自訂名稱為「專案素材」或「待發郵件」。

多色彩識別標籤

系統內建 6 款調和色彩（天青藍、翡翠綠、活力橘、優雅紫等），每個架子顏色各自獨立。

06

偏好設定詳解

在托盤圖示點右鍵 ➔ 選擇「⚙️ 偏好設定」，或在未釘選的置物架點選齒輪圖示即可進入設定面板。

⚡

晃動靈敏度調整 (1 ~ 5 級)

預設為「等級 3（標準）」。如果您平常滑鼠移動幅度較大、容易誤觸，可調為「等級 1 ~ 2（防誤觸偏鈍）」；若希望極速微晃即現身，可調為「等級 4 ~ 5（極靈敏）」。

⌨️

全域快捷鍵錄製

點擊快捷鍵輸入框即可直接在鍵盤按下任意組合鍵（例如 Alt + Space 或 Ctrl + Shift + X），系統會即時辨識並綁定。

常見問題與疑難排解

Q1：為什麼晃動滑鼠沒有反應？

請確認您是在「按住滑鼠左鍵抓住檔案」的狀態下晃動。若仍無反應，請至「⚙️ 偏好設定」確認「啟用滑鼠晃動召喚」已勾選，並可嘗試將靈敏度調高至等級 4 或 5。

Q2：防毒軟體彈出警告是否正常？

正常。因為 KyteShelf 必須使用 Windows 系統底層的滑鼠勾點（Global Mouse Hook）技術來偵測您是否正在拖曳並搖晃滑鼠。本軟體 100% 不含任何木馬或回傳隱私代碼，請放心加入信任名單。

Q3：日常使用需要保持聯網嗎？

不需要！ KyteShelf 採用強固的離線簽名授權架構。只有在初次輸入序號開通的那一秒需要連網，驗證完成後本機會簽發離線憑證，未來在無網路的飛機上、保密辦公室斷網環境下均 100% 永久離線可用。
