在日常使用 Windows 10 或 Windows 11 的過程中，「跨資料夾與跨視窗搬移檔案」往往是最容易打斷專注力的痛點之一。許多曾使用過 macOS 的專業工作者對 **Dropover** 愛不釋手，卻苦於在 Windows 上找不到同樣直覺、輕量且流暢的原生替代方案。

## 傳統 Windows 檔案拖放的三大痛點

- **視窗並排混亂**：為了把散落在不同子目錄的素材集中起來，往往得同時開啟 3 個以上的檔案總管視窗並排對齊。
- **工作列懸停手痠**：按住滑鼠左鍵把檔案拖到工作列圖示上等待目標視窗彈出，稍微手滑就會掉進錯誤的資料夾。
- **跨螢幕長距離拖移**：在雙螢幕或 21:9 超寬螢幕環境下，死按著滑鼠橫跨數千像素極度消耗手腕精力。

## KyteShelf：專為 Windows 量身打造的「推車式中繼站」

[KyteShelf](../index.html) 採用「先暫存、後釋放」的非同步拖放哲學。當你在任何位置按住檔案並**輕微左右晃動滑鼠游標**（或按下 `Ctrl + ~`），懸浮置物架就會自動在游標旁浮現。

### 核心亮點功能

- **五級防誤觸晃動召喚 (Shake to Summon)**：精準識別拖曳手勢，放開滑鼠後雙手即可完全離開滑鼠，從容切換至目標軟體再一次拖出。
- **萬物皆可剪貼簿貼入 (`Ctrl + V`)**：除了實體檔案，無論是剛截好的螢幕截圖、網頁圖片網址，還是臨時複製的備忘文字，都能直接貼入置物架成為獨立便箋或圖片檔。
- **內建一鍵 ZIP 壓縮與批次圖片縮放**：收集完分散在各處的交付素材後，點擊底部按鈕即可原地打包為 `.zip` 壓縮檔。
- **與 KyteView 空白鍵預覽深度連動**：在置物架內選取任何檔案按下 `Space` 空白鍵，即可毫秒級彈出檔案內容預覽，確認無誤再拖出。

> 無論你是設計師、工程師還是行政企劃，將「尋找檔案」與「放置檔案」拆解為兩個無壓力的步驟，都能讓每日桌面操作效率翻倍。
