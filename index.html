Core Features

精心打磨的每個微小細節

不只是一個暫存盒，而是全面升級你的 Windows 操作直覺。

晃動即刻召喚

抓住檔案並左右輕微晃動，置物架立刻出現於手邊；也可使用全域快捷鍵 Ctrl + ~ 隨叫隨到。

收集好各路徑檔案後，點擊底部 ZIP 按鈕或右鍵選單，原地直接打包壓縮，整理分享一氣呵成。

深度整合 Windows COM 介面，選取檔案右鍵即可自動掛載至正在編輯的 Outlook 郵件草稿中。

常見問答

有任何疑問嗎？這裡整理了大家最常問的問題。

Q：支援哪些 Windows 版本？

KyteShelf 專為 64 位元的 Windows 10 與 Windows 11 系統設計與測試，全面相容系統原生暗色與亮色主題。

Q：防毒軟體會誤報嗎？

由於本軟體使用全域滑鼠勾點（Hook）來偵測「晃動召喚」手勢，少數防毒軟體可能出現誤判提示。本專案原始碼在 GitHub 具備透明度，保證不含任何惡意程式碼，安裝時請安心點擊「允許執行」。

Q：更換電腦或重灌系統怎麼辦？

每組購買的正式版序號最多允許同時啟用 2 台個人裝置。若您重灌電腦或更換硬體，可隨時聯繫開發者為您重置授權額度。
